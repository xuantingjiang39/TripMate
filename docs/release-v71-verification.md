## 发现与改进

真实本地 Chromium 中延迟后台 GET，然后切换至旅行偏好并输入未保存的过敏提醒；v70 在响应返回后把输入替换为云端偏好。390/1280px 均复现。这是受控复现，不代表已确认线上用户发生过数据丢失。

v71 在请求前及响应应用前检查编辑状态；表单所在页面、输入焦点、打开的对话框、隐藏页面及生成中状态会暂缓自动刷新。返回阅读页面后按原轮询周期恢复。不拦截正常保存上传，不新增表单自动保存，不改变主动载入云端/恢复备份流程。

## 手动安装

上传 `TripMate-server-v71-update.zip` 到 `/home/ubuntu/` 后执行：

```bash
mkdir -p /home/ubuntu/tripmate-update-v71
cd /home/ubuntu/tripmate-update-v71
unzip -t /home/ubuntu/TripMate-server-v71-update.zip &&
unzip -o /home/ubuntu/TripMate-server-v71-update.zip -d . &&
sudo bash ./update-tripmate.sh
```

预期健康版本：`v71-edit-safe-refresh`。国际站另手动上传 `TripMate-pages-v71-upload.zip` 到原 `tripmate` Pages 项目。

# v60 交付核验 · 2026-11-07

## 已实现
- 两站设置新增合并入口，国内生成一次性连接码，国际已登录用户明确勾选记录传输授权，预览后再确认。
- 行程、订单、提醒、费用、行李合并；仅同编号同内容去重。不同单号同价订单、无编号记录均保留，同编号不同内容更换副本编号保留两份。另一份草稿转存我的行程，偏好和应急卡可选保留来源，原始内容有备份。
- 国内服务端保留合并前原始快照，国际私有 D1 保存原始快照和历史备份。退出共享前拷贝当前主记录；用户可下载云端、本机未同步、历史备份。
- 共享以国内账号为主记录；登录、管理员权限、AI 额度与账本仍独立，不迁移密码，不自动连接真实账号。
- 新增两张 D1 表，保留原有账号/会话/状态表与绑定。Node 用户 JSON 仅新增受限授权和备份字段，不改变数据目录和已有配置。

## 安全与一致性
- 连接码 256 位随机、10 分钟有效、存哈希、一次消费；待确认授权20分钟过期，启用后可从国内停用。
- 共享能力只允许旅行记录；不能登录、访问额度或管理员接口。
- 浏览器直接访问国内固定 HTTPS IP；CORS 仅精确允许官方国际站，拒绝其他 Origin，不使用凭据跨站发送 Cookie，不把能力令牌放入 URL/localStorage。共享令牌对本人客户端可见，属于受限 Bearer 凭证，仅在内存使用；私有 D1 存储用于持久连接。
- 原因：Cloudflare Workers 官方已知限制不允许 fetch 直接访问 IP URL，未发布一个依赖该不支持路径的后端代理。参考 https://developers.cloudflare.com/workers/platform/known-issues/ 。
- 国内 CAS 校验版本、确认请求幂等；旧预览不能确认新选择；国际预览期间冻结普通云端写入，避免两个站合并时丢修改。
- 国际网页处理保存途中继续修改、脏副本拉取/重载、网络中断。冲突时不覆盖本机，先导出再由用户明确采用云端副本；备份后若又编辑，拒绝替换。
- 合并预览含原始备份上限1.4MB，超限拒绝，不截断。网页新增记录不再按旧20/100条上限丢弃已合并记录。

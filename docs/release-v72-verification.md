# v72 定位会话与停止保护验证

2026-11-16，以 PROJECT 指定的 guest-v71 / 配套 Pages 为基线。现有服务器最近确认仍为 v70，本次没有部署。Windows v54、Android v58、签名与工具链均未更改。

## 发现的问题

- 旧导航只清除 GPS 监听，没有使排队回调失效，也没有取消在途浏览器请求。停止后旧响应仍能显示路线，已排队的位置回调还能再次查询。
- 手机端自动打开地图的 180ms 定时器没有停止检查，可能在点击停止后继续跳转。
- 首次进入时将空的日期值保留为 `''`，下拉框无选中项，实际路线却按第 1 天计算。

## 本次改进

每次导航独立编号并绑定当前账号与路线；请求发出和返回时检查会话。停止先使旧会话失效，再清除 GPS 监听、取消浏览器请求、撤销延迟跳转并清空运行中的位置引用。旧结果、错误及收尾不能改变新会话。

切换日期、打开另一条路线、退出/切换账号和页面关闭时结束原定位；需要时重新点击开始。重复开始不增加监听，启动定位同步抛错时恢复按钮。首次进入明确选择第 1 天。

取消浏览器请求不能撤回已经发送的位置，也不能保证终止服务器/上游已开始的处理；本次修复不作此承诺。没有新增轨迹存储。

## 手动安装

上传 `TripMate-server-v72-update.zip` 到 `/home/ubuntu/`：

```bash
mkdir -p /home/ubuntu/tripmate-update-v72
cd /home/ubuntu/tripmate-update-v72
unzip -t /home/ubuntu/TripMate-server-v72-update.zip &&
unzip -o /home/ubuntu/TripMate-server-v72-update.zip -d . &&
sudo bash ./update-tripmate.sh
```

# v64 日常检查与验证

2026-11-08。当前源码依据 PROJECT.json 和 README 检查，未修改历史版本或部署远程服务器。

## 问题与根因

v63 国际 transport 在任何退出响应返回时都会清除令牌，未核对响应是否还属于当前会话。在确定性延迟响应测试中，先退出、后新登录、旧退出最后返回，v63 删除了新令牌；测试原版明确失败。

此外，网页退出回调在 await 后无条件清除当前用户；通用 JSON 消费者在响应体解析后未重新核对用户。因此旧退出回调和旧账号的额度等接口有机会影响新账号界面。

## 完成改进

- 国际退出发起时推进会话代际并清除本标签页用户/游客令牌；原撤销请求携带原令牌。
- 响应头和鉴权响应体解析完成时核对代际，丢弃过期响应；旧登录不能恢复退出后的会话。
- 国内/国际非鉴权 JSON 接口解析后核对当前用户及游客对象。旧账号数据不会交给 UI 消费者。
- 退出 UI 回调核对发起者，不能清除后来登录的账号或重置其界面。
- 未删除数据、修改额度、账号库、第三方/HTTPS 配置，也未更新 App 签名。

## 复现与修复

`node tools/verify-v70-snapshot-reads.mjs guest-v69`：向实际旧轮询函数返回 `{stateVersion:6}`，本机草稿和订单从有内容变成 `{}`，保护断言失败，复现数据清空路径；这不是声称线上用户已经丢失记录。

共享模块增加 decodeSnapshot：要求明确的对象 state、数字安全整数版本及已知容器结构；不将缺失、null 或数组当空记录，不把字符串版本强制转数字。后台/手动载入拒绝版本回退。检查在存储写入、更新同步基准、归档或清除日志之前完成。异常不自动重试写入；过期账号的提示回调不会改变新账号状态。明确有效的空状态仍可应用。

# v59 设置与站点切换核验 · 2026-11-07

## 改进
- 旧版站点下拉入口不明显，改成顶部直接显示“切换到国际站 / 切换到国内站”，手机与桌面均可见。
- 设置入口包含 44 种语言、字号（标准/大字）、减少动画，保存于当前浏览器。
- 44 种语言仅覆盖设置、站点和基础按钮；原中英日词典覆盖更多页面。未覆盖的文字以英文或原文显示，生成内容不翻译；不是全球全部语言的完整翻译。
- 阿拉伯语、希伯来语、波斯语、乌尔都语支持 RTL。字号增大或长语言按钮换行时自动测量顶栏高度，避免遮住页面和设置。
- 只把 lang/textSize/motion 传至固定白名单站点；不传递当前 URL 中其他参数、Cookie、凭证或行程。跨站账号仍独立。

# v57 · 直接从服务器下载安装包

安卓 APK 与 Windows 安装文件随完整更新包附带。更新后，下载页的主按钮访问本站 `/downloads/文件名`，不再跳转 GitHub。GitHub 发布页保留为备用来源。

下载接口采用流式传输，支持 HEAD、单段 Range、后缀范围及 If-Range；下载中断后浏览器可继续。仅允许两个固定公开文件名，不开放目录列表、配置或账号数据库。未知文件返回 404，安装文件缺失或大小异常时返回 503。

## 自己安装：推荐上传完整包

1. 在腾讯云 OrcaTerm 打开文件管理，上传 `TripMate-server-v57-direct-downloads.zip` 到 `/home/ubuntu`。本机完整包位于 `C:\codex\TripMate\TripMate-server-v57-direct-downloads.zip`。
2. 在服务器 Ubuntu 终端执行：

```bash
mkdir -p /home/ubuntu/tripmate-update-v57
unzip -o /home/ubuntu/TripMate-server-v57-direct-downloads.zip -d /home/ubuntu/tripmate-update-v57 && cd /home/ubuntu/tripmate-update-v57 && sudo bash update-tripmate.sh
```

也可以让服务器从 GitHub 下载一次完整更新包：

```bash
mkdir -p /home/ubuntu/tripmate-update-v57
cd /home/ubuntu/tripmate-update-v57
curl -fL --retry 3 -C - https://github.com/xuantingjiang39/TripMate/releases/download/v57/TripMate-server-v57-direct-downloads.zip -o update.zip && unzip -o update.zip && sudo bash update-tripmate.sh
```

初次获取完整更新包仍可能受 GitHub 网络影响；已上传本地 ZIP 时不用再次下载。访客更新后的主下载链路直接访问腾讯云服务器。

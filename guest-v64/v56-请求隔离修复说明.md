# v56 · 异常请求隔离

日期：2026-11-07。当前本地服务器版本：`v56-request-isolation`。只读检查线上 `/api/health` 和 `/download` 均为 HTTP 200，线上版本仍是 v55；本次未自动部署。

## 发现的问题与修复

在隔离目录启动原 v55，通过本地 HTTP 复现：只要账号接口收到不能解码的 Cookie 值，异步处理函数就会抛出未捕获异常，Node 进程以状态 1 退出。这会让其他正在登录、保存行程或生成攻略的人也短暂无法连接。

v56 只跳过无法解码的 Cookie，保留同一请求中的有效会话。请求地址格式错误返回 400；请求内部发生未预料的异常时，隔离当前请求并返回不含路径或数据库内容的 500 提示，其他访问继续服务。对于已经开始发送的流式响应，关闭该次连接，不向流中混入其他格式的数据。

未修改账号存储结构、密码、会话策略、AI 价格、扣费和旅行数据。未改动 SMTP、DeepSeek、高德、美团或 HTTPS 配置脚本。保留软件下载入口；国内 COS 下载地址尚未提供，本版不会宣称下载已加速。

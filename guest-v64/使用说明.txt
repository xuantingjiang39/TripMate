TripMate 服务器安装包（v43 真实地图导航版，不包含任何 API 密钥）

1. 将整个 ZIP 上传到服务器用户目录。
2. 在服务器终端运行：
   mkdir -p /home/ubuntu/tripmate-install
   unzip -o /home/ubuntu/TripMate-server-v43-real-map-navigation.zip -d /home/ubuntu/tripmate-install
   cd /home/ubuntu/tripmate-install
   sudo bash install.sh
3. 安装完成后运行：sudo set-tripmate-deepseek-key
4. 按提示输入 1 个 DeepSeek API 密钥；默认使用 deepseek-flash 并关闭思考模式。
5. 运行 sudo set-tripmate-amap，输入高德开放平台创建的 Web 服务 Key。
6. 运行 sudo set-tripmate-meituan，在服务器终端隐藏输入美团个人开发者 Token。
7. 没有域名时运行：sudo set-tripmate-https-ip 111.230.133.155 tripmate@yeah.net
8. 看到 HTTPS 验证成功后，打开 https://111.230.133.155。

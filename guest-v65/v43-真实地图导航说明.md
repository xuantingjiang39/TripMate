# TripMate v43 真实地图导航

- 安卓 App：点击“开始地图导航”后，TripMate 判断下一站并直接调起高德地图；未安装高德时回退到高德网页路线。
- 网页：手机端定位完成后自动尝试调起高德地图，电脑端提供高德网页地图入口。
- TripMate 页面只保留下一站、剩余距离、预计时间和进度，不再展示冗长的逐句路线说明。
- 返回 TripMate 后可重新判断下一站；点击停止或关闭页面即停止 TripMate 的前台定位。
- 沿用 v42 的步行、驾车和跨城距离保护，避免 `OVER_DIRECTION_RANGE`。

现有 `AMAP_WEB_KEY` 继续用于服务端判断下一站，不需要新增密钥。若未来要求把高德地图完整嵌入 TripMate 内部，需另行申请绑定 `com.tripmate.travel` 与 APK SHA-1 的 Android 导航 SDK Key。

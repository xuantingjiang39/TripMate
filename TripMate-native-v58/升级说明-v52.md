# TripMate v52 / Android 1.1.4

日期：2026-11-01。

## 发现的问题

旧版会把同步接口中缺失的 `state` 字段当作空账号数据。在模拟接口只返回空对象的情况下，原本已加载的攻略与离线副本会被替换为空。保存确认没有有效版本号时，也可能过早移除待同步更改。

## 本次修复

- 验证同步返回的数据对象和非负整数版本号；格式异常时保持当前行程及离线副本。
- 区分“真正的空账号”和“接口缺字段”，仍允许合法的空状态与版本 0。
- 校验保存确认是否返回预期的新版本；缺失或错误时继续保留待同步操作。
- 多设备冲突后重新读取的数据同样经过校验，异常时不继续提交，避免基于错误数据覆盖账号内容。
- 接口恢复后仍能合并重试，并保留其他设备的订单与原攻略。

## 安装

手机打开同目录 `TripMate-v52-android-v1.1.4.apk`，覆盖旧版。不要先卸载。

电脑 ADB：

```sh
adb install -r TripMate-v52-android-v1.1.4.apk
```

服务器无需升级。本轮未部署远程服务器，未调用收费 AI 接口，未删除账号、行程、额度或邮箱、DeepSeek、高德、美团配置，也未向手机传输或安装文件。

尚未取得 Mate30 的实际下载或安装报错，本版本不代表此前的下载问题已解决。

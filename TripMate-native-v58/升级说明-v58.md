# v58 / Android 1.1.5 · 简洁旅行界面

适用于已安装的旅伴 TripMate，可直接覆盖安装；不要先卸载。包名仍为 `com.tripmate.travel`，versionCode 16，原账号、离线行程、额度和同步保护逻辑保留。

## 界面改进

- “今天”只保留一个主要地图导航按钮，去掉重复的可点击导航卡片；当天事件标题直接可见，详细说明点击展开。
- 完整攻略、行程概况与出发提醒放到今日安排之后，减少首屏信息。
- 交通详情随选中的行程日显示，未标明日期的交通放入独立可展开区域，不丢失原记录。
- 规划模板与额度说明按需展开；额度评估与确认生成仍分两步，不自动扣费。
- “我的”页面折叠隐私、权限及连接帮助，优先展示账号和额度；错误提示保持可见。

## 安装

打开 `TripMate-v58-android-v1.1.5.apk`，选择覆盖安装。支持 Android 7.0 及以上、ARMv7 / ARM64。已有 v52 签名一致；Windows 客户端不需要重装。

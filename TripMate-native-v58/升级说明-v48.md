# TripMate 1.1.0 · v48

2026-10-25。本轮升级基于原生 Android v1.0.9，账号和服务继续连接现有 TripMate 服务端。

## 可以直接感受到的变化

- 完整攻略增加“安排、交通、住与吃、费用”四个页面区块。
- “行程”支持搜索和打开收藏；兼容网页版保存的记录格式。
- 首页、完整攻略、地图导航共用所选日期；有日历日期时自动匹配当天。
- 已同步的账号行程保存到当前手机，下次短暂断网也能查看。
- 临时断网不再清空登录；登录失效仍需重新验证。
- 生成成功但同步失败时保留本机攻略，显示“重试同步”，避免让用户重新生成。
- 替换当前攻略时保留原稿；保存时读取服务器最新版本并合并行程操作，保留订单与偏好等其他数据。
- 先评估并展示 AI 点数，再确认生成；避免连点重复请求，网络请求有明确超时。
- 导航回调使用最新进度，退出页面后旧定位结果不会重新启用监听；从高德返回时尝试更新位置。
- 大屏使用侧边导航，手机底栏适配系统安全区；长按钮文字可换行。
- 酒店餐厅支持来源图片、来源/预订链接；费用缺失显示“待核实”。
- 增加系统分享攻略、应用内连接诊断和定位权限设置入口。

## 安装

安卓手机直接打开同目录 APK，覆盖安装旧版。不要先卸载。

电脑 ADB：

```sh
adb install -r TripMate-v48-android-v1.1.0.apk
```

服务器无需执行升级命令。原账号、AI 额度、DeepSeek、邮箱、高德、美团配置保持现状。本包没有自动部署或改动远程数据。

离线副本需先在本版联网成功读取一次；首次升级时建议先打开账号与行程，再出发。打开官方预订页面和首次计算地图路线仍需要网络。

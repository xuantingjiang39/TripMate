# v59 设置与国际站切换

页面顶部始终显示“切换到国际站 / 切换到国内站”和“设置”。
设置支持 44 种语言的基础按钮与设置标签；中英日覆盖更多页面文字，其他文字回退英文或原文。不是全球语言全文翻译，已有行程不会自动翻译。
可调标准/大字及减少动画；自动保存当前浏览器，切站只传递语言、字号、动画偏好，不传账号凭证或旅行数据。两个站账号独立。
现有 Android v58 和 Windows v54 安装文件不变；本次只升级网页及服务器静态资源。
保留已有数据库、账号、行程、订单、额度、SMTP/API 密钥、HTTPS；无需重新配置。

## 更新
含完整安装文件的本地 ZIP：TripMate-server-v59-settings.zip。
公开轻量 ZIP：TripMate-server-v59-update.zip，会复用服务器已有且校验正确的安装文件；缺少时从官方 GitHub Release 补下载并核对 SHA256。
上传完整包到 /home/ubuntu 后：
```
mkdir -p /home/ubuntu/tripmate-update-v59
unzip -o /home/ubuntu/TripMate-server-v59-settings.zip -d /home/ubuntu/tripmate-update-v59
cd /home/ubuntu/tripmate-update-v59
sudo bash update-tripmate.sh
```
不自动部署腾讯云服务器。Sites 国际站通过既有站点单独发布。

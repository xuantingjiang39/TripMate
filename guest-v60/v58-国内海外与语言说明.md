## 自己更新国内服务器

推荐把本机 `C:\codex\TripMate\TripMate-server-v58-regional-language.zip` 上传到服务器 `/home/ubuntu`，然后执行：

```bash
mkdir -p /home/ubuntu/tripmate-update-v58
unzip -o /home/ubuntu/TripMate-server-v58-regional-language.zip -d /home/ubuntu/tripmate-update-v58 && cd /home/ubuntu/tripmate-update-v58 && sudo bash update-tripmate.sh
```

也可从 GitHub 下载小型更新包。脚本先复用服务器上校验正确的安装文件，只下载缺少的新文件；准备失败时不会更新运行中的服务：

```bash
mkdir -p /home/ubuntu/tripmate-update-v58
cd /home/ubuntu/tripmate-update-v58
curl -fL --retry 3 -C - https://github.com/xuantingjiang39/TripMate/releases/download/v58/TripMate-server-v58-update.zip -o update.zip && unzip -o update.zip && sudo bash update-tripmate.sh
```

保留账号、行程、订单、额度、SMTP、DeepSeek、高德、美团及 HTTPS 配置；不需要重新输入密钥。本次不自动部署腾讯云。

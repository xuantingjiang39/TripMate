# 旅伴 TripMate Windows 版 1.0.1（v54）

2026-11-01。适用 Windows 10 / 11 64 位。

## 安装与使用

双击 `TripMate-v54-Windows-1.0.1-Setup.exe`，选择安装目录，完成后从桌面或开始菜单打开“旅伴 TripMate”。也可解压便携 ZIP 后打开 `TripMate.exe`；不要单独移动其中的 EXE，需保留整个目录。本版更新旅行路线与日出图标，详见 [图标说明](图标说明-v54.md)。

使用现有 TripMate 邮箱账号登录。电脑客户端通过 HTTPS 加载现有旅行工作台，行程、订单和 AI 额度继续使用原服务器。首次打开需要登录，软件不会读取浏览器或手机的密码。是否允许多个设备同时登录由现有服务器的会话策略决定。

这是联网桌面客户端，包含独立窗口、Windows 安装和卸载、快捷方式及桌面下载能力；它复用现有在线工作台，并非全部功能离线运行的软件。

- 顶部“导出 PDF”将当前行程保存为横向 A4 PDF；登录或进入游客体验后使用。
- `Ctrl+P` 导出行程；`Ctrl+R` 刷新前会提醒保存未完成输入。
- `＋ / − / 100%` 调整工作台字号。
- 酒店、餐厅、购票和地图的外部 HTTPS 链接在默认浏览器打开；下单和付款由对应平台完成。
- 首次使用定位会询问授权。电脑定位可能不准确或不可用，可以手动填写当前位置；本版本不承诺具备手机 GPS 的精度。
- 断网、超时、证书异常会显示恢复入口。证书异常不能通过关闭验证绕过。

Windows 首版未购买商业代码签名证书，安装程序的发布者可能显示未知。请核对文件来自本次交付；不需要更改杀毒软件或系统安全设置。

## 数据与服务器

服务器地址固定为 `https://111.230.133.155`；无需更新服务器或重新填写 DeepSeek、高德、美团、SMTP 等密钥。应用不携带这些服务密钥。

桌面客户端的会话 Cookie 和工作台本地数据保存在当前 Windows 用户的应用数据目录中，与手机及浏览器隔离。电脑共用时请在工作台退出账号。卸载默认保留本机数据；本次不会自动删除账号、行程或额度。

## 构建

需要 Node.js 和 npm，在源码目录运行：

```powershell
npm ci
node node_modules/electron/install.js
npm test
npm run test:desktop
npm run dist
```

`test:desktop` 使用隔离的临时用户目录，首次仅检查线上匿名登录页面；后续请求全部拦截到本地测试夹具，不提交真实账号、不调用收费 AI。

安装包生成于 `dist`；桌面文件由 Electron 45.2.1、electron-builder 26.18.0 构建。测试和源码不进入最终应用。生产渲染页面禁用 Node、开启 sandbox/contextIsolation/webSecurity，远程页面只有受主进程来源校验的 PDF 导出能力。

## 验证范围

已检查真实 HTTPS 登录页；隔离测试覆盖登录/注册切换、游客示例、字号、800px 紧凑窗口、外部链接限制、实际 PDF 生成和断网恢复。四组策略测试覆盖来源、IPC 来源、危险协议和错误分类。新增桌面页面的 Impeccable 机械检查无发现。

测试不使用真实登录凭据，不验证真实下单、付款、AI 扣费、GPS 或第三方库存。电脑客户端沿用现有服务器网页，因此安卓 1.1.4 独有的本地实现不会自动迁移到电脑客户端。

框架安全设置参考：[Electron 官方安全文档](https://www.electronjs.org/docs/latest/tutorial/security)。

# v55 · 网页软件下载入口

网页顶部及登录卡片加入「软件下载」。无需登录即可访问 `/download`，选择 Android APK 或 Windows 安装包，查看系统要求与 SHA-256。手机、电脑布局分别适配；识别设备只作提示，不自动下载。iPhone / iPad 使用网页版。

本版本的 Windows 安装包仍为 v54 / 1.0.1，Android 仍为 v52 / 1.1.4；下载直达公开 GitHub Releases，不通过旅行服务器转发大文件。GitHub 在部分网络可能无法访问，可继续使用网页版。

## 更新现有服务器

本地发布不等于线上部署。需在服务器执行以下命令；下载与解压成功后才运行更新脚本：

```bash
mkdir -p /home/ubuntu/tripmate-update-v55
cd /home/ubuntu/tripmate-update-v55
curl -fL --retry 2 https://github.com/xuantingjiang39/TripMate/releases/download/v55/TripMate-server-v55-downloads.zip -o TripMate-server-v55-downloads.zip && unzip -o TripMate-server-v55-downloads.zip && sudo bash update-tripmate.sh
```

更新只安装应用文件，沿用原账号、行程、订单、额度和服务器配置；不需要重新输入 SMTP、DeepSeek、高德或美团密钥，不需要重新申请 HTTPS 证书。不要对已安装服务器运行全新安装脚本。

更新后访问 `https://111.230.133.155/download`，或刷新首页点击「软件下载」。健康接口应显示 `v55-download-page`：

```bash
curl -fsS https://111.230.133.155/api/health
```

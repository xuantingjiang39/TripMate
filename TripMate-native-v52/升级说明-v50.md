# TripMate v50 / Android 1.1.2

日期：2026-10-30。

## 发现的问题

旧版保存离线攻略时先清空原文件，再写新内容。模拟手机空间不足或写入中断时，写入失败会连原来的离线攻略一起损坏。另外，离线保存失败的提示可能被后续联网同步成功清掉，让人以为已经可以离线查看。

## 本次改进

- 轮换保存两份本机副本，只覆盖较旧或已损坏的一份，保留最新完整副本。
- 写入后读回并校验全部内容；写入不完整也不会误报成功。
- 读取时采用最新完整副本；其中一份损坏时可退回另一份。
- 兼容 v48/v49 的单文件副本，保留待同步行程操作和账号隔离。
- 离线保存失败提示独立保留，真正写入成功后才清除。提示用户检查存储空间，并将未同步更改联网保存后再退出。

本机副本无法代替服务器备份；第一次成功离线保存前仍需联网读取行程。双副本保护针对写入中断或其中一份损坏，不保证手机系统被清除、卸载应用或两份同时损坏后的恢复。

## 安装

手机直接打开同目录 `TripMate-v50-android-v1.1.2.apk`，覆盖上一版。不要先卸载。

电脑 ADB 安装：

```sh
adb install -r TripMate-v50-android-v1.1.2.apk
```

无需操作服务器。账号、行程、AI 额度及邮箱、DeepSeek、高德、美团配置保持原状。本轮未部署远程服务器，未调用收费 AI 接口，未删除现有用户数据。

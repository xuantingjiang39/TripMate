# TripMate v51 / Android 1.1.3

日期：2026-10-31。

## 发现的问题

收藏去重与攻略切换原先只比较标题、每日安排和预算。即使酒店、餐厅、交通购票说明或出行提醒已经更新，也可能被当成同一份攻略：新的收藏不出现，或替换草稿时没有保留旧内容。

测试在修改前复现了该缺陷：应保留两份内容不同的收藏，实际只有一份。

## 本次改进

- 按完整行程内容判断是否为同一版本，覆盖推荐、来源与预订链接、交通说明、摘要和提醒，也保留以后新增的内容字段。
- 同名但内容不同的旧收藏继续显示并可打开；切换攻略时原稿和其他账号字段保持完整。
- 字段排列顺序或 AI 计费余额变化不再造成重复收藏。
- 只有实际日程变化才重置所选日期与导航；酒店、餐厅或提醒更新不会打断手选的日期。
- 原有账号保护、离线双副本和导航监听保护保持不变。

## 安装

手机打开同目录 `TripMate-v51-android-v1.1.3.apk`，直接覆盖旧版。不要先卸载。

电脑 ADB：

```sh
adb install -r TripMate-v51-android-v1.1.3.apk
```

服务器无需升级。本轮未部署远程服务器，未调用收费 AI 接口，未删除已有账号、行程、额度或邮箱、DeepSeek、高德、美团配置。

本版本解决收藏内容判断问题。尚未取得 Mate30 的实际安装报错，也未在 Mate30 上验证安装，不能据此认为此前的下载或安装问题已经解决。
